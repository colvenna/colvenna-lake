# Third-party source and license records

Colvenna Lake's original source code, deployment code, documentation and brand assets are distributed under [Apache-2.0](LICENSE). Third-party components keep their own licenses, recorded below. Redistribution must keep the license and notice files each component ships with (for jars, their `META-INF/LICENSE` and `NOTICE`; for container images, those their packages install); this record does not replace them.

The licenses below were read on 2026-10-27 from the Maven Central POMs, the PyPI metadata, `deploy/aws/package-lock.json`, the upstream LICENSE files at the pinned versions, and the labels and build history of the pinned image digests. This is the maintainers' engineering record, not legal advice. What could not be established is marked UNKNOWN; audits that were not run are marked NOT_RUN.

## Third-party material in this repository

### Archify

The interactive architecture diagram [`docs/design/diagrams/colvenna-lake-architecture.html`](docs/design/diagrams/colvenna-lake-architecture.html) is generated by [Archify](https://github.com/tt-a1i/archify/tree/v3.2.0) 3.2.0 and includes its viewer runtime code, under MIT. The HTML file itself does not carry Archify's notice: it is in [third_party/archify.LICENSE](third_party/archify.LICENSE), as the LICENSE of the Archify 3.2.0 package that generated the file has it, and must accompany any copy of the diagram. Apache-2.0 does not replace it for those portions. The diagram uses none of the third-party brand marks that Archify packages.

### JetBrains Mono

The same HTML file embeds the JetBrains Mono variable WOFF2 subsets served by Google Fonts (revision v24). Copyright 2020 The JetBrains Mono Project Authors ([github.com/JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono)), under the SIL Open Font License 1.1, whose full text the file carries in its font stylesheet. No other file in the repository embeds a font.

### Apache Doris configuration files

[`deploy/scripts/doris/fe-default.conf`](deploy/scripts/doris/fe-default.conf) and [`be-default.conf`](deploy/scripts/doris/be-default.conf) are the configuration files the Apache Doris 4.1.4 images ship, kept with their ASF license headers (Apache-2.0); the install derives the query engine's configuration from them. The Apache Doris NOTICE attribution is in [NOTICE](NOTICE).

### OpenLineage schemas (tests only)

[`colvenna-operator/src/test/resources/openlineage/spec/`](colvenna-operator/src/test/resources/openlineage/README.md) holds the OpenLineage 2-0-2 specification and facet schemas as released in OpenLineage 1.54.0, under Apache-2.0. The operator's tests validate events against them offline; they are not packaged into any image.

### Brand assets and diagrams

The Colvenna series mark is the series' own asset, drawn by [`assets/brand/generate.py`](assets/brand/generate.py) (Apache-2.0) as the series' brand generator draws it; provenance and usage rules are in the [brand guide](assets/brand/README.md). The brand SVGs and the static architecture SVG embed no fonts, scripts or images: they name Arial, Helvetica, Noto Sans CJK SC and system sans-serif fonts, which the viewer's machine supplies. The architecture SVG is written by the project's own [`render_architecture.go`](assets/architecture/render_architecture.go), which uses only the Go standard library. The PNGs are rasterized with `rsvg-convert`; which installed fonts rendered the committed PNGs is not recorded (UNKNOWN). Rendered glyphs carry no font software.

### Overview video

[`assets/video/`](assets/video/) holds only the rendered outputs: `colvenna-lake-promo.gif` and `colvenna-lake-promo.mp4` (H.264 video, AAC audio). No code or font files are bundled. The editable project was made with the html-to-explainer-video tool and is kept outside this repository; the fonts rendered into its frames and the text-to-speech service that voiced it are not recorded here (UNKNOWN). The video ends with the ASF trademark attribution ([naming record](release/trademarks.md), section 6).

### Quotations in research reports

The reports in [`docs/research/`](docs/research/) quote the official documentation of Apache Paimon, Apache Iceberg, Apache Hudi, Apache Doris, Apache Flink, Apache Fluss and AWS. That material remains the copyright of those projects and of AWS; the reports use it as design reference.

## Not yet audited

The following have not run (NOT_RUN), and this record does not claim them:

- a transitive SBOM of the Maven runtime dependencies, the Go indirect modules, Superset's Python environment and the npm lock file;
- the content of the shaded jars (the Flink CDC and Kafka connectors, `paimon-hadoop-uber`, `paimon-bundle`, `iceberg-aws-bundle`) and of the Apache Doris images' bundled libraries;
- the operating system packages of every base and third-party image;
- a legal review: of the copyleft and source-available components above (MySQL Connector/J in the operator and job images, `mysqlclient` and `psycopg2-binary` in the BI image, Logback, Grafana, MySQL, BusyBox, MongoDB), of the source-offer obligations that come with the redistributed images, and of the Red Hat UBI terms.

Recorded as UNKNOWN: the fonts that rendered the committed PNGs, and the overview video's fonts and voice service.
